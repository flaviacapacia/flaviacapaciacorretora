Cadastrar / gerar imóvel

Preencha, importe de um link ou cole o texto do anúncio. Depois gere a página.

1. Importar de um link (opcional)

Busca título, descrição, preço e imagens da página. Nem todo portal libera — se falhar, use o texto livre.

2. Dados do imóvel

Dados internos do CRM — não vão para o HTML do site.

Use quando não tiver link. Depois revise os campos abaixo.

Ícones em img/icons/: quartos, banheiro, vaga, areaprivativa, churrasqueira, elevador, arcondicionado, petfriendly, salaodefestas.

3. Imagens

Nomes dos arquivos na pasta img/vCÓDIGO/ ou URLs. Separe por vírgula ou linha.

4. Publicar card no index

Os dados são preenchidos ao gerar a página. Publique localmente e faça o push só quando conferir.

SEO · Artigo do bairro

Depois de publicar o imóvel, gere um artigo do bairro para posicionamento orgânico no Google.

Card de Lançamento
